Title: Vending Machine
Purpose: A small vending machine simulator
Instructions: Choose one of the given options by inputting the required integer. Enter the demanded amount of cash to get your item.
Example:

Input: 1, then 200, then n.
Output: 
Please select one of the following
1. Red Bull[Rs. 200]
2. Coke[Rs. 80]
3. Fanta[Rs. 100]
4. Nescafe Latte[Rs. 150]
5. Dew[Rs. 80]
6. Sprite[Rs. 80]
7. Mango Juice[Rs. 50]
(input 1)

then

Please Deposit 200
(Type in the value)
(input 200)

then 

Enjoy Your Drink!
Do you want to buy another drink?
y or n
(input n)

Program Ends.
